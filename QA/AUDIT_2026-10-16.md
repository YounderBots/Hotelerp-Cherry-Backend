## Decisions needed (not changed)

1. **GST is charged before the discount**, everywhere: both venues' bills and
   the hotel folio compute tax on the pre-discount amount. Under GST a discount
   shown on the invoice normally reduces the taxable value. Changing it alters
   every total, so it needs the owner's call.
2. **A table reservation blocks the table from the moment it is made.**
   Reserving for 8 pm sets the table to Reserved immediately, and the Orders
   screen offers only Available tables, so it cannot take walk-ins all day.
3. **No refund path for venue bills.** A-01 makes part-paid bills
   settle-only. If cancelling with a refund is needed, it is a new feature.

## Observations, low severity, not fixed

- `PUT /restaurant/table_reservation/{id}` to Cancelled/Completed/No-Show sets
  the table Available even when an order is open on it. Not reachable from the
  screens (the Orders screen cannot open an order on a non-Available table);
  API only.
- `POST /bill/{id}/split` (both venues) marks the order Paid/Completed and frees
  the table once the *first* share is paid. No screen calls it and the gateway
  fails it closed as unmapped, so it is unreachable today. Fix before wiring it.
